### Road Maps Scene
> **요약:** 로드맵 카테고리를 보여주는 씬입니다. 탭을 클릭하면 해당 버튼의 위치에서부터 화면 전체로 확장되는 '원형 마스킹(Radial Masking) 트랜지션'을 구현하여 고도화된 UI/UX를 제공합니다.

#### 주요 로직
* **월드 좌표 기반 원형 마스크 확장 연출 (`RadialTransitionManager`):** * 클릭된 UI 엘리먼트(`RectTransform`)를 타겟으로 삼아, 해당 UI의 좌표를 중심으로 화면 전체를 덮는 Radial Mask 확장을 수행합니다.
  * 단순히 화면 중앙에서 퍼지는 것이 아니라, 유저가 누른 버튼의 월드 좌표(World Space)를 계산하여 정확한 기점에서부터 마스킹이 팽창 및 축소되도록 수학적 연출을 구현했습니다.
* **비동기 시퀀스 기반의 뷰 컨트롤 (`SwitchSequence` & `ShrinkSequence`):** * 현재 활성화된 인덱스(`_activeIndex`)를 추적하여, 사용자의 조작에 따라 트랜지션 로직을 동적으로 분기합니다.
  * **같은 탭 클릭 시:** 열려있던 화면이 다시 버튼 위치로 빨려 들어가듯 축소(`ShrinkSequence`).
  * **다른 탭 클릭 시:** 열려있던 화면이 먼저 축소된 후, 새로 클릭한 버튼의 위치에서 다시 화면이 팽창(`SwitchSequence`)하는 다단계 코루틴 시퀀스를 정밀하게 설계했습니다.
* **동적 오브젝트 풀링을 이용한 카테고리 스와핑 (`CategoryUIManager`):** 무거운 스크롤 뷰 컨텐츠(로드맵 데이터)를 매번 Instantiate하지 않고, 카테고리별로 `ObjectPool`을 할당했습니다. 화면이 원형 마스크로 완전히 덮이는 시점(블라인드 타이밍)에 내부 컨텐츠를 즉각적으로 스왑하여 렌더링 프레임 저하를 방지했습니다.

#### 트러블슈팅: 좌표계 변환 및 비동기 애니메이션 상태 충돌(Overlap) 해결
* **문제 1 (좌표계 한계):** UI가 Canvas 내부에 존재하기 때문에, 단순 `anchoredPosition`으로는 다양한 해상도와 화면 비율에서 원형 마스크의 중심점을 정확히 타겟팅하고 화면 전체를 덮는 반경(Radius)을 계산하기 어려웠습니다.
* **해결 1:** 타겟 UI의 `RectTransform`에서 추출한 값을 월드 좌표계로 치환하고, 이를 다시 스크린/캔버스 비율에 맞게 역산하여 이펙트 컨트롤러(`UIRadialEffect`)에 `centerRect` 데이터로 전달함으로써 해상도에 독립적인 완벽한 마스킹 처리를 구현했습니다.

* **문제 2 (상태 꼬임 현상):** 사용자가 팽창/축소 애니메이션이 끝나기 전에 다른 버튼을 연속으로 클릭하거나, 여러 버튼을 동시에 누르면 코루틴이 중첩 실행되어 마스킹이 화면에 끼어버리거나 스크롤바가 오작동하는 치명적인 버그가 발생했습니다.
* **해결 2 (방어 코드 및 상태 추적기 도입):**
  * **디바운싱(Debouncing):** `RadialTransitionTrigger`에 `ClickCooldown(0.1s)`을 적용하여 하드웨어적인 중복 클릭을 1차적으로 차단했습니다.
  * **코루틴 추적 및 킬링(Kill):** `_transitionCoroutine` 변수로 현재 실행 중인 애니메이션 상태를 캐싱하고, 새 클릭 이벤트가 발생하면 기존 코루틴을 즉시 강제 종료(`StopCoroutine`)시킨 후 새로운 시퀀스를 할당하는 '상태 머신' 기법을 적용했습니다.
  * **동적 UI 제어:** 팽창/축소 과정에서 시각적 노이즈를 유발하는 스크롤바(`scrollbarCanvasGroup`)를 `DOTween`을 이용해 트랜지션 전후로 투명도(Alpha)와 상호작용(Raycast)을 완벽히 통제하여 깔끔한 연출을 완성했습니다.

AI의 도움을 가장 많이 받은 부분입니다. 월드 좌표를 마스킹 중심점으로 변환하는 수학적 계산이나, 코루틴 시퀀스가 꼬이는 문제를 디버깅할 때 AI를 적극 활용했습니다. 단순히 코드를 복사한 것이 아니라, '상태가 중첩되어 꼬이는 문제'의 원인이 코루틴 비동기 실행에 있다는 것을 파악하고, 이를 `_transitionCoroutine`이라는 변수로 캐싱해 강제 중단(StopCoroutine)시키는 아키텍처를 AI와 함께 설계하며 비동기 프로그래밍에 대한 이해도를 크게 높일 수 있었습니다.
